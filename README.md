# Universal-EMC
| 初試模組製作 |
| ProjectE 個人附屬 |
| 一個自動設定模組包裡所有物品EMC的模組，有必要可以接入個人API。 |

| 指令 | 功能 |
|---|---|
| `/uemc scan` | 重新掃描物品與配方，計算並套用 EMC |
| `/uemc preview` | 只計算、產生報告，不修改 EMC |
| `/uemc status` | 查看目前處理狀態 |
| `/uemc reset` | 移除本模組管理的 EMC 設定，並關閉自動掃描 |
## API 設定

使用個人 API 的設定方式，請參閱 [API 設定教學](API.md)。
